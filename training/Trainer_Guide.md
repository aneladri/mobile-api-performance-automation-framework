# MAPAF Training Guide

## Training Duration

5 Days

## Audience

* QA Engineers
* Automation Engineers
* SDETs
* New Team Members

## Objectives

Participants should be able to:

* Execute API tests
* Create API automation
* Execute Android tests
* Create Android page objects
* Execute iOS tests
* Create iOS page objects
* Run performance tests
* Generate Allure reports
* Analyze failures using MAPAF AI foundations
