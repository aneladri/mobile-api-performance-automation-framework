# iOS Lab 01 - Settings Validation

## Objective

Validate Settings application using MAPAF.

## Application

Settings

Bundle ID:

```text
com.apple.Preferences
```

## Tasks

1. Launch iOS simulator.
2. Execute iosTest.
3. Validate Settings screen.
4. Validate Search field.
5. Review screenshot in Allure.

## Run

```bash
gradle iosTest
```

## Validation

* Session created
* Settings app launched
* Search field visible
* Screenshot attached

## Learning Outcome

* iOS execution
* XCUITest
* Page Objects
