# Android Lab 01 - Launch Application

## Objective

Launch ApiDemos application using MAPAF.

## Application

ApiDemos-release.apk

## Tasks

1. Start Appium.
2. Start Android Emulator.
3. Execute mobileTest.
4. Verify application launches.
5. Review Allure report.

## Run

```bash
gradle mobileTest
```

## Validation

* App launches successfully
* Screenshot attached in Allure

## Learning Outcome

* Android execution flow
* Driver creation
* Reporting
