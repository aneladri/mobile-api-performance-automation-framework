# MAPAF v2.7.4 Integration Assets

- **Postman:** `postman/RoomScan-Digital-Twin.postman_collection.json` is generated by `apiRoomScanDigitalTwinDemo` and can be executed with Postman or Newman after setting `baseUrl`, `scanId`, and `jobId`.
- **Prometheus:** `performance/reports/prometheus/roomscan-production.prom` is generated by `performanceProductionDemo`.
- **Grafana:** `grafana/roomscan-production-dashboard.json` is generated/importable as a starter dashboard definition.
- **Allure:** deterministic failure showcases publish attachments and are categorized through `performance/scripts/publish-allure-metadata.sh`.

These integrations are real artifact contracts. External servers are not bundled; Grafana, Prometheus, Postman/Newman and Allure CLI must be installed separately when live tool execution is required.
