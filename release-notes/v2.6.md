# MAPAF Enterprise v2.6 - Executive Command Center

## Highlights
- Executive and Engineering role-based views
- Aggregation of Mobile, Web, API and Performance enterprise summaries
- Release-readiness score, business risk and recommendation
- AI-ready executive narrative
- Missing module support through `NOT_RUN`
- Clickable evidence and report links
- Dashboard JSON contract for future integrations

## Commands

```bash
./gradlew executiveDashboardUnitTest
./gradlew frameworkDashboardDemo
```

## Outputs
- `dashboard/reports/index.html`
- `dashboard/reports/executive-summary.json`

## Compatibility
All existing quick demos, enterprise demos and dashboard code remain intact.
