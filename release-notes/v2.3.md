# MAPAF Enterprise v2.3 — Common Enterprise Runtime

## Highlights
- Added a reusable enterprise execution context with execution, correlation and trace identities.
- Added shared evidence registry and evidence types.
- Added common quality-gate evaluator.
- Added centralized sensitive-data masking.
- Added API and Performance adapters for the shared reporting contract.
- Added AI-agent governance policy and analysis record.
- Added TestNG regression coverage and `enterpriseRuntimeTest` Gradle task.

## Backward compatibility
Existing quick and enterprise demo tasks are unchanged.

## Validation commands

```bash
./gradlew clean compileTestJava
./gradlew enterpriseRuntimeTest
./gradlew apiEnterpriseDemo
./gradlew performanceEnterpriseDemo
```

## Known limitations
Mobile and Playwright enterprise demos have not yet migrated to the shared runtime. This is planned for subsequent releases.
