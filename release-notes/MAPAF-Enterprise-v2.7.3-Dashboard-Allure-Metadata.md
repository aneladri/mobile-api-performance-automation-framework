# MAPAF Enterprise v2.7.3

## Dashboard navigation and Allure metadata hotfix

- Adds a visible **Open detailed report** action to every module card.
- Links the command center to `mobile.html`, `web.html`, `api.html`, and `performance.html`.
- Publishes `environment.properties`, `executor.json`, and `categories.json` before Allure generation.
- Preserves Allure history when regenerating the report so trend data can accumulate across runs.
- Keeps existing quick demos, enterprise demos, presentation profiles, and report contracts unchanged.
