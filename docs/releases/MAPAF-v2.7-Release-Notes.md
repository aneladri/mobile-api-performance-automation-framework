# MAPAF Enterprise v2.7 Release Notes

## Release name
Allure Showcase and Presentation Mode

## Added

- Guided presentation orchestration.
- FULL, ENGINEERING, and EXECUTIVE profiles.
- Automatic Mobile, Playwright, API, and Performance execution.
- Dashboard refresh and opening.
- Allure report generation and opening.
- Stage timing and PASS/FAIL tracking.
- Presentation summary JSON.

## Compatibility

Existing demo tasks remain unchanged. v2.7 composes the existing enterprise tasks instead of replacing them.

## Known constraints

- The FULL profile requires a working mobile device/emulator.
- `allure open` remains active until the Allure server is stopped.
- Browser and desktop opening commands are macOS-oriented.
