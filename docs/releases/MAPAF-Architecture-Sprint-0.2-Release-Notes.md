# MAPAF Architecture Sprint 0.2 Release Notes

## Release theme

Platform Core architecture and executable reference kernel.

## Added

- Capability contract, descriptor, type and normalized result.
- Capability registry with duplicate protection.
- Execution request, context, identity factory, engine and outcome.
- Governed platform event vocabulary and thread-safe in-memory event bus.
- Platform Core architecture, domain, contract, event and migration documentation.
- C4-style Mermaid architecture diagrams.
- ADR-012 through ADR-016.
- Architecture and runtime TestNG gates.
- Idempotent Gradle installer and validation tasks.

## Compatibility

This release is additive. It does not replace or modify existing Mobile, Web, API, Performance, Reporting or Allure execution paths.
