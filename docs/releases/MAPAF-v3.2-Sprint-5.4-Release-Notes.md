# MAPAF v3.2 Sprint 5.4 Release Notes

## Knowledge Integration

This sprint adds a governed knowledge layer for MAPAF agents.

### Contracts

- `mapaf.knowledge.document/v1`
- `mapaf.knowledge.query/v1`
- `mapaf.knowledge.result/v1`
- `mapaf.knowledge.evidence/v1`

### Capabilities

- Local repository knowledge
- Replay Confluence, SharePoint, and Google Drive sources
- Deterministic keyword and metadata retrieval
- Evidence-backed search results
- Read-only document retrieval
- Approval-controlled index refresh
- Prohibited source deletion
- JSON evidence publishing
- Full inherited regression through Sprint 5.3
