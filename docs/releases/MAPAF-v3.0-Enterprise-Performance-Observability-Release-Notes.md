# MAPAF v3.0 Enterprise Performance Observability Foundation

## Added

- Docker Compose observability stack with Prometheus, Grafana, and OpenTelemetry Collector.
- Prometheus remote-write execution for governed k6 workloads.
- Provisioned MAPAF k6 enterprise Grafana dashboard.
- Observability doctor, validation, start, stop, and status commands.
- Observed smoke, load, spike, and exact-volume Gradle tasks.
- Contract tests and rollback-safe installer.

## Compatibility

The increment is additive. Existing MAPAF k6 tasks, JMeter compatibility, normalized HTML reports, Allure evidence, and Unified Dashboard generation remain available.
