# Claude Architect Agent

## Purpose

The Claude Architect Agent reviews MAPAF architecture and identifies design risks, technical debt, scalability concerns, and improvement opportunities.

The agent acts as an architecture reviewer and governance mechanism for the framework.

---

## Responsibilities

* Architecture Reviews
* Design Validation
* Scalability Assessment
* Technical Debt Identification
* Refactoring Recommendations
* Governance Reviews
* Framework Maturity Assessment

---

## Inputs

* Java Package Structure
* Gradle Configuration
* TestNG Suites
* GitHub Actions Workflows
* ADR Documents
* Framework Documentation
* Agent Documentation

---

## Outputs

* Architecture Score
* Design Risks
* Technical Debt Findings
* Refactoring Recommendations
* Scalability Recommendations
* Governance Recommendations

---

## Success Criteria

* Maintain clean layer separation
* Prevent framework degradation
* Ensure scalability
* Support future AI capabilities
* Improve maintainability
