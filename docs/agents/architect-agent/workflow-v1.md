# Architect Agent Workflow v1

## Purpose

Review framework architecture and identify risks and opportunities.

---

## Input

* Package Structure
* Build Configuration
* CI/CD Workflows
* Documentation
* ADR Documents
* Agent Definitions

---

## Processing Steps

### Step 1

Analyze framework structure.

### Step 2

Validate layer separation.

### Step 3

Identify technical debt.

### Step 4

Evaluate scalability.

### Step 5

Review governance compliance.

### Step 6

Generate recommendations.

---

## Output Format

Architecture Score:

Design Risks:

Technical Debt:

Refactoring Opportunities:

Scalability Recommendations:

Governance Recommendations:

Confidence Score:

---

## Success Criteria

* Accurate architecture assessment
* Actionable recommendations
* Early technical debt detection
* Consistent framework governance
