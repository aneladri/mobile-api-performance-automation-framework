# Claude Orchestrator Agent

## Purpose

Coordinate all MAPAF AI agents and produce a consolidated engineering recommendation.

## Participating Agents

- Failure Analysis Agent
- Documentation Agent
- Architect Agent
- Performance Analysis Agent

## Inputs

- Failure Logs
- Test Results
- Performance Results
- Documentation Changes
- Architecture Changes

## Outputs

- Root Cause Analysis
- Documentation Impact
- Architecture Impact
- Performance Impact
- Recommended Actions

## Success Criteria

Provide a single actionable engineering recommendation.
