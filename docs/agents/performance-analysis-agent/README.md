# Claude Performance Analysis Agent

## Purpose

The Claude Performance Analysis Agent reviews MAPAF performance test results and identifies performance regressions, threshold breaches, trend changes, and optimization opportunities.

## Responsibilities

- Analyze K6 performance results
- Compare current run against baseline
- Identify response time regressions
- Identify error rate increases
- Identify throughput drops
- Recommend performance investigation areas
- Generate performance summary reports

## Inputs

- K6 execution output
- Threshold results
- Baseline metrics
- Historical performance reports
- GitHub Actions artifacts
- Performance strategy documents

## Outputs

- Performance classification
- Regression summary
- Threshold breach analysis
- Root cause hypothesis
- Recommended next actions
- Confidence score

## Success Criteria

- Performance regressions are identified early
- Threshold breaches are explained clearly
- Recommendations are actionable
- Historical trends are used for comparison
