# Claude Architect Agent

## Purpose

Review the framework design and identify architectural risks.

## Inputs

- Java package structure
- Build configuration
- TestNG suites
- CI/CD workflows
- Framework documentation

## Review Criteria

- Layer separation
- DRY compliance
- Page Object purity
- No driver leakage
- Config externalization
- Reusability
- Scalability
- CI/CD readiness

## Output

- Architecture score
- Design risks
- Refactoring suggestions
- Priority recommendations
