# MAPAF v2.9 Compatibility Matrix

- Java: 21
- Gradle wrapper: repository-provided version
- macOS: supported for Android and iOS diagnostics
- Linux: supported for non-iOS execution
- Playwright Chromium: required for Browser Health
- Appium/ADB/Xcode: optional unless the selected device execution mode requires them
- k6/JMeter: required for direct performance execution
