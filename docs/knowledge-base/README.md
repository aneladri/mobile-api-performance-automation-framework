# MAPAF Knowledge Base

## Purpose

The MAPAF Knowledge Base stores reusable engineering knowledge used by all AI agents.

## Knowledge Domains

### Failure Corpus

Stores:

* Failure patterns
* Failure examples
* Root causes
* Resolutions

### Performance Corpus

Stores:

* Baselines
* Regressions
* Threshold failures
* Performance recommendations

### Architecture Corpus

Stores:

* ADRs
* Architecture reviews
* Refactoring recommendations

### Documentation Corpus

Stores:

* Documentation recommendations
* Changelog patterns
* Roadmap decisions

## Agent Usage

Agents consume knowledge from this repository to improve consistency and recommendation quality.

## Governance

Knowledge should be:

* Accurate
* Reusable
* Versioned
* Reviewable
