# Platform Core Architecture Gate

A Sprint 0.2 change is accepted only when:

- platform-core contracts compile without vendor dependencies;
- architecture and runtime tests pass;
- five Sprint 0.2 ADRs remain accepted;
- required architecture artifacts are present;
- duplicate capability IDs are rejected;
- execution identity is propagated;
- lifecycle events are emitted in deterministic order;
- no existing enterprise demo task is removed;
- migration remains adapter-based and reversible.
