# MAPAF Sprint Delivery Standard

Every sprint must deliver:
1. Architecture: updated diagrams and decisions.
2. Development: working production-quality code or executable platform tooling.
3. Unit Tests: regression-safe automated coverage.
4. Enterprise Demo: reproducible production-ready demonstration.
5. Documentation: user, engineering, and operational documentation.
6. Release Notes: versioned change and migration record.
7. ZIP Release: verified framework package.
8. Demo Validation: end-to-end validation of tasks, reports, links, and artifacts.

A sprint is incomplete when any mandatory artifact is missing.
