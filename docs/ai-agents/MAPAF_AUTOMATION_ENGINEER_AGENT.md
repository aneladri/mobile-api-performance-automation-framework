# MAPAF Automation Engineer Agent

## Purpose

The MAPAF Automation Engineer Agent helps generate automation assets from business intent.

It supports:

- UI automation generation
- API automation generation
- Room Scanner workflow automation
- Framework-compliant screen objects
- Business flows
- Test classes
- TODO placeholders for missing locators or APIs

## Integration

The agent works with:

- Claude Code for developer-assisted code generation
- Anthropic Claude API for framework runtime AI services
- MAPAF AutomationGenerationEngine
- MAPAF Prompt Library
- MAPAF Feature Package Writer
