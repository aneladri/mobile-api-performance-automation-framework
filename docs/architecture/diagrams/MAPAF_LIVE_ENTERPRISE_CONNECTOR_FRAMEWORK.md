# MAPAF Live Enterprise Connector Framework

Capability requests are resolved to replay, live, or hybrid enterprise connectors. Live providers use environment-backed secret references, connector health assessment, normalized MAPAF models, approval governance, and audit evidence.

```text
Agent / Skill / Workflow
        -> Capability Request
        -> Connector Resolver
        -> REPLAY | LIVE | HYBRID
        -> Azure DevOps | Jira | GitHub
        -> Normalized MAPAF Model
        -> Audit Evidence
```
