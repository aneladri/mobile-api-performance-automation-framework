# ADR-011: Establish Architecture Governance

- Status: Accepted
- Date: 2026-08-01

## Decision
Material changes require an ADR. Every sprint must provide architecture, working code, tests, enterprise demo, documentation, release notes, verified ZIP, and demo validation.

## Review Gates
- domain ownership
- dependency direction
- contract compatibility
- security and privacy
- observability
- failure behavior
- test and migration strategy
