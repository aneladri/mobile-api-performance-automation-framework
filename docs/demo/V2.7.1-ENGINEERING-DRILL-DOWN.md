# MAPAF Enterprise v2.7.1 - Engineering Drill-Down

Generate the command center after running the enterprise demos:

```bash
./gradlew frameworkDashboardDemo
open dashboard/reports/index.html
```

Each module card now includes **View execution details**.

The detail pages provide:

- execution IDs and correlation IDs
- step-by-step timelines when published
- business objectives and workflow states
- API requests, masked headers, payloads, responses, assertions and latency
- browser diagnostics, trace, video and network evidence
- performance engine metrics, percentiles, bandwidth and quality gates
- direct links to raw summaries and evidence reports

Enterprise demos publish detailed steps beginning with v2.7.1. Existing older summary files remain compatible and show an explicit message when detailed steps are unavailable.
