# MAPAF Training Plan

## Overview

This programme is designed to take a new engineer from:

```text id="start"
No MAPAF knowledge
```

to:

```text id="end"
Independent contributor
```

within five training days.

---

# Programme Duration

```text id="duration"
5 Days
```

Recommended:

```text id="schedule"
6–7 hours per day
```

---

# Day 1

## Labs

```text id="d1"
Lab 00 – Introduction to MAPAF

Lab 01 – Project Setup

Lab 02 – Framework Architecture
```

## Learning Objectives

Understand:

* What MAPAF is
* Why MAPAF exists
* Framework architecture
* Project structure

## Checkpoint

Trainee explains:

* Core Layer
* Mobile Layer
* API Layer
* AI Layer
* Performance Layer

---

# Day 2

## Labs

```text id="d2"
Lab 03 – API Testing

Lab 04 – Android Testing
```

## Learning Objectives

Create:

* API Tests
* Android Screen Objects
* Android Test Cases

## Checkpoint

Trainee creates:

* One API test
* One Android test

---

# Day 3

## Labs

```text id="d3"
Lab 05 – iOS Testing

Lab 06 – Performance Testing
```

## Learning Objectives

Understand:

* iOS automation
* BrowserStack
* Smoke Tests
* Load Tests
* Stress Tests

## Checkpoint

Trainee executes:

* iOS test
* Smoke test
* Load test

---

# Day 4

## Labs

```text id="d4"
Lab 07 – AI Analysis

Lab 08 – Debugging & Troubleshooting
```

## Learning Objectives

Understand:

* Failure Analysis
* Healing Recommendations
* Performance Analysis
* Debugging Workflow

## Checkpoint

Trainee investigates:

* Locator failure
* API failure
* Performance regression

---

# Day 5

## Labs

```text id="d5"
Lab 09 – Git Workflow

Lab 10 – Capstone Project
```

## Learning Objectives

Demonstrate:

* Git proficiency
* Framework understanding
* Independent execution

## Checkpoint

Capstone assessment completed.

---

# Evaluation Criteria

| Area                | Weight |
| ------------------- | ------ |
| API Testing         | 15%    |
| Android Testing     | 15%    |
| iOS Testing         | 15%    |
| Performance Testing | 15%    |
| AI Analysis         | 15%    |
| Debugging           | 15%    |
| Git Workflow        | 10%    |

---

# Graduation Criteria

Engineer must:

* Complete all labs
* Pass checkpoints
* Complete capstone
* Demonstrate debugging skills

---

# Outcome

Successful trainees can:

* Create tests independently
* Debug failures independently
* Interpret AI reports
* Contribute to MAPAF development
