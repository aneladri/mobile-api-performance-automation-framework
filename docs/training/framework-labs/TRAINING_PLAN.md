# MAPAF Training Plan

## Six-day plan

| Day | Focus | Practical outcome |
|---|---|---|
| 1 | Setup and architecture | Framework compiles; API baseline passes |
| 2 | API testing | Payload, schema, auth, mock API tests |
| 3 | Mobile | Appium lifecycle, screens, flows, tests |
| 4 | Performance | Portable JMeter setup, k6/JMeter smoke and load |
| 5 | AI and debugging | Analysis, healing, locator discovery |
| 6 | Capstone and demo | Repeatable end-to-end demonstration |

## Day 4 detailed agenda

1. Performance concepts and workload models.
2. Standalone mock API architecture.
3. Portable JMeter installation for managed Macs.
4. k6 smoke and result interpretation.
5. JMeter non-GUI smoke and dashboard interpretation.
6. Equivalent-workload comparison.
7. Delay/error injection.
8. Docker execution and CI discussion.

## Required completion evidence

- tool/version checks;
- k6 summary;
- JMeter JTL and HTML dashboard;
- target metrics;
- short comparison of tool fit;
- documented troubleshooting and cleanup.
